# VFX照明 LEDテープ資料

BTF-LIGHTING WS2811 DC12V LEDテープを、ENTTEC OCTO MK3 で点灯させるための資料です。

| ファイル | 内容 |
|---|---|
| `LEDテープ組立説明書.pdf` / `.html` | 部品の確認から、テープ1本の組立、複数本の接続、トラブル対処まで |
| `LEDテープ単体点灯テスト.pdf` / `.html` | PC を使わず、テープ1本が点灯するかを確認する手順 |
| `img/` | 組立説明書で使う画像（BTF-LIGHTING の販売ページより） |

HTML を編集したら、ブラウザで開いて A4 で PDF に印刷すると、PDF を作り直せます。
