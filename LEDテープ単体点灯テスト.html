LEDテープ 単体点灯テスト手順

ENTTEC OCTO MK3 ／ BTF-LIGHTING WS2811 DC12V LEDテープ（5m）／ 海渡電子 ACアダプター 12V 5A
PC・TouchDesigner・ネットワーク接続なしで、テープ1本が正しく点灯するかを確認する手順です。

はじめに：このLEDテープは、電源をつなぐだけでは点灯しません。各LEDに「何色で光るか」という信号（データ）が必要です。このテストでは OCTO MK3 本体の Identify ボタンでテスト信号を出して確認します。

1. 準備するもの（テープ1本分）

LEDテープ1本 ＋ 付属の 3ピンコネクター（片側が電線むき出しのもの）
ACアダプター1個 ＋ 付属の DCジャック プッシュ式コネクター（赤・黒のボタン付き）
コントローラーENTTEC OCTO MK3
ワンタッチコネクターWAGO 3本用 ×1、5本用 ×1
電線スピーカーケーブルを 10〜15cm に切ったもの ×4本（線A〜D）
工具ワイヤーストリッパー、精密マイナスドライバー

2. 配線図

赤＝＋（プラス）、濃い灰色＝－（マイナス／GND）、緑＝データ。WAGO の同じコネクターに差した線どうしはすべてつながります。

3. 配線手順

重要：配線が終わるまで、ACアダプターはコンセントに差さないでください。

テープの入力側の端（矢印が始まる側）には、3ピンのメスコネクターと、電源線2本（赤＝＋、白＝－）が出ています。

  1. DCジャックコネクターの ＋ と － に、短い電線を1本ずつ差します（線A、線B）。
  2. ＋側：WAGO 3本用に、線A・テープの赤い電源線・OCTOへ行く線C を差します。
  3. －側：WAGO 5本用に、線B・テープの白い電源線・OCTOへ行く線D・3ピンコネクターの白い線（GND） を差します。
  4. 線C を OCTO の POWER 端子の＋ に、線D を － に、ドライバーで固定します。
  5. 3ピンコネクターの緑の線（データ）を、OCTO 出力ポートの DATA 端子に固定します。
  6. 3ピンコネクターの赤い線（12V）は使いません。先端をビニールテープで巻いて、他の金属に触れないようにします。
  7. 3ピンコネクターを、テープの入力側コネクターに差し込みます。

WAGO の使い方：レバーを上げる → 被覆を約1cm むいた電線を奥まで差す → レバーを下げる。

4. 電源を入れる前のチェック

  • ＋ と － が入れ替わっていない（赤い線どうし・白い線どうしが同じ WAGO にある）
  • WAGO のレバーがすべて下がっていて、電線を軽く引っ張っても抜けない
  • 緑の線が OCTO の DATA 端子に入っている（POWER 端子ではない）
  • 使わない赤い線の先端が絶縁されている
  • むき出しの銅線どうしが触れ合っていない

5. 点灯確認

  1. ACアダプターをコンセントに差します。OCTO のランプが点灯します。
  2. OCTO 本体の Identify / Reset ボタンを短く押します。
  3. テープにテストパターンが表示されれば、配線は成功です。
注意：ボタンを長押しすると設定の初期化になる場合があります。短く押してください。

6. 点灯しないとき

OCTO のランプが点かないOCTO の電源配線（線C・線D）と、DCジャックコネクターの差し込みを確認します。
OCTO は点くがテープが光らない ① 3ピンコネクターがテープの入力側（矢印が始まる側）に差さっているか確認します。
② 緑の線が DATA 端子に入っているか確認します。
③ OCTO のピクセル設定が WS2811 になっていない可能性があります。PC と LAN ケーブルでつなぎ、ブラウザで OCTO の設定画面（初期 IP：192.168.0.10）を開いて、プロトコル：WS2811／ピクセル数：100 に設定します。
色が指定と違う故障ではありません。OCTO の設定画面で色の並び順（RGB／GRB など）を変更すれば直ります。
異常に熱い・焦げたにおいすぐにコンセントを抜き、＋と－の配線を確認してください。

7. 補足

  • WS2811 テープは、ICチップ1個で LED 3個をまとめて制御します。5m で 100ピクセル（約5cm 単位）です。
  • 作業する電線はすべてアダプターを通した 12V なので感電の危険はありませんが、配線の変更は必ずコンセントを抜いてから行ってください。
